## Overview

FetchMedia provides a unified API for fetching videos from social media platforms such as TikTok, Instagram, YouTube, LinkedIn, X, and Facebook. You process these videos server-side with FFmpeg for tasks such as trimming, adding watermarks, or converting formats. Integrate FetchMedia into your workflows with tools like n8n, Make, or any HTTP client to automate video fetching, editing, and repurposing.

## Quick Start

Get started in minutes.

<Steps>
  <Step title="Sign Up" icon="user-plus" title-type="p">
    Create an account at `https://app.fetchmedia.io` and generate your API key.
  </Step>

  <Step title="Fetch a Video" icon="download" title-type="p">
    Use this example to fetch and process a TikTok video.

    <CodeGroup show-lines="true" tabs={[]}>
      ```javascript
      const response = await fetch('https://api.fetchmedia.io/v1/fetch', {
        method: 'POST',
        headers: {
          'X-API-KEY': 'YOUR_API_KEY',
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          url: 'https://www.tiktok.com/@user/video/123456789'
        })
      });
      const data = await response.json();
      console.log(data.fetch_id);
      ```

      ```bash
      curl -X POST https://api.fetchmedia.io/v1/fetch \
        -H "X-API-KEY: YOUR_API_KEY" \
        -H "Content-Type: application/json" \
        -d '{
          "url": "https://www.tiktok.com/@user/video/123456789"
        }'
      ```

      ```python
      import requests

      response = requests.post(
          'https://api.fetchmedia.io/v1/fetch',
          headers={
              'X-API-KEY': 'YOUR_API_KEY',
              'Content-Type': 'application/json'
          },
          json={
              'url': 'https://www.tiktok.com/@user/video/123456789'
          }
      )
      print(response.json()['fetch_id'])
      ```
    </CodeGroup>
  </Step>

  <Step title="Download Processed Video" icon="save" title-type="p">
    Access the `fetch_id` from the response to retrieve your edited video.
  </Step>
</Steps>
